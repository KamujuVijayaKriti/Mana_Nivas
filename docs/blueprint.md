# **App Name**: Mananivas - Smart Housing Platform

## Core Features:

- User Authentication & Access Control: Secure sign-up and login with role-based access control (seeker/lister/admin).
- User Profile Management: Enable users to create, read, update, and delete their profiles, including profile photos, bio, and contact details.
- Property Listing & Management: Allow listers to add, read, update, and delete property listings, including details, location, features, pricing, and photos.
- Advanced Property Search & Filters: Implement a search form and filter options to find properties based on location, price range, type, and features.
- Real-Time Chat & Messaging: Enable real-time chat between seekers and listers for direct communication.
- AI-Powered Property Description Tool: Generates suggested property descriptions from structured data provided by listers, to help less web-savvy people create higher quality property listings.
- Admin Dashboard: Provide an admin interface to manage users, properties, and system reports.

## Style Guidelines:

- Primary color: Soft blue (#A0CFEC) to evoke trust and reliability, suitable for a housing platform.
- Background color: Light gray (#F0F4F8), a slightly desaturated tone from the primary hue, ensuring a clean, non-distracting backdrop.
- Accent color: Pale violet (#B290EC) to contrast and highlight important elements without overwhelming the soft aesthetic.
- Font pairing: 'Poppins' (sans-serif) for headlines, giving a contemporary feel, and 'PT Sans' (sans-serif) for body text, to make longer texts readable. 
- Use consistent, outline-style icons to represent property features and navigation elements.
- Employ a clean, grid-based layout for property listings, ensuring information is easily scannable.
- Incorporate subtle animations for loading states and transitions to enhance user experience without being distracting.
