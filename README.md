
🏠 Mana Nivas

👉 **Live Website:** https://mana-nivas.vercel.app/ 

Mana Nivas is a modern property listing and management web application built using Next.js.
The platform allows users to explore properties, manage listings, save favorites, and handle user authentication through a clean and responsive interface.

🚀 Features

🏘️ Browse available property listings

🔍 View detailed property information

❤️ Save favorite properties

👤 User authentication (Signup / Profile)

🛠️ Property management dashboard

⚡ Fast performance using Next.js and Turbopack

📱 Fully responsive UI (mobile, tablet, desktop)
